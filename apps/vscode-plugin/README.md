# vscode-plugin

`vscode-plugin` 是 `honoapp` 的 VS Code 插件入口。

## 当前版本

- `0.2.0`
- 插件中心与活动栏统一使用紫色 `<>` 图标，避免与 VS Code 内置图标混淆。
- VS Code 窗口启动完成后检查 `127.0.0.1:3005`。
- 端口已经被占用时不再重复启动服务。
- 端口空闲时启动 VSIX 内置的 `honoapp`；服务启动后独立常驻，不跟随 VS Code 窗口关闭。
- 状态栏和活动栏显示服务状态，点击后用默认浏览器打开服务。

此文件记录插件的公开版本说明。项目任务的编号、状态和验证结论只维护在项目根目录 `README.md` 的 `任务台账` 中；更新插件后，以该台账的对应任务为准，不在此处复制第二份台账。
